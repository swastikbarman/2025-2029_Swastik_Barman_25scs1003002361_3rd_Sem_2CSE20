# Student Record Management System in C

A simple, menu-driven C program built during my 6-week C Programming Virtual Internship with BeeSkilled.

## 📌 About the Project
This project helps maintain basic student academic records in the console using core C concepts like structures, functions, arrays, and pointers.

- **Author:** Swastik Barman
- **Roll No:** 25SCS1003002361
- **University:** IILM University, Greater Noida
- **Platform:** BeeSkilled

---

## ✨ Features
- **Add Student:** Enter student name, roll number, and marks.
- **Display Students:** View all saved student records in a clean table.
- **Search Student:** Find any student instantly using their roll number.
- **Calculate Average:** Automatically compute the class average marks.

---

## 🛠️ Tech Stack
- **Language:** C (C99)
- **Compiler:** GCC
- **Editor:** VS Code

---

## 🚀 How to Run

1. **Compile the code:**
   ```bash
   gcc main.c -o student_manager
